# Indian Election & Politics Assistant — NaagrikInfo

## Vision
An interactive, modern web application that helps Indian citizens understand the election process, explore their elected representatives (MPs, MLAs) across all states, and track government promise fulfillment with data-driven visualizations. Built with a 2026-era design aesthetic.

## Tech Stack
- **Frontend:** HTML, CSS, JavaScript (vanilla — no frameworks for size constraint)
- **Design:** Modern 2026 aesthetics — glassmorphism, mesh gradients, micro-animations, saffron-white-green-blue palette
- **Data:** Embedded JSON datasets for MPs, MLAs, states, and government promises
- **Charts:** Canvas-based chart rendering (custom lightweight — no chart libraries)
- **Constraints:** Total GitHub repo size must stay under 10MB

## Goals
1. Educate Indian citizens on the election process (Lok Sabha, Rajya Sabha, Vidhan Sabha)
2. Searchable database of all 543 Lok Sabha MPs and state-wise MLAs
3. Interactive government promises tracker with visual graphs (promised vs fulfilled)
4. Modern, premium 2026 UI with Indian tricolor-inspired design
5. Lightweight — under 10MB total repo size
6. Accessible and responsive across devices
