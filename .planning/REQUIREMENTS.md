# Requirements

## REQ-001: Indian Election Process Education
The app must clearly explain India's election system — Lok Sabha (543 seats, FPTP, direct election), Rajya Sabha (245 seats, STV, indirect election by MLAs), and State Vidhan Sabha elections. Include ECI role, voter eligibility, NOTA, EVM/VVPAT process.

## REQ-002: Comprehensive MP Database
Searchable database of all 543 Lok Sabha MPs with: name, constituency, state, party, and party affiliation. Filterable by state and party. Data embedded as JSON.

## REQ-003: Comprehensive MLA Database
Searchable database of MLAs for all 28 states and 3 UTs with assemblies (~4,120 seats total). Include: name, constituency, state, party. Filterable by state and party.

## REQ-004: State-wise Explorer
Interactive India map or state selector showing: number of Lok Sabha seats, Vidhan Sabha seats, current ruling party, key political data for each state/UT.

## REQ-005: Government Promises Tracker
Visual graphs comparing government manifesto promises vs fulfillment status. Categories: Infrastructure, Economy, Welfare, Health, Education, Agriculture. Each promise has status: Fulfilled, In Progress, Not Started, Modified. Use canvas-based charts (bar, donut, progress).

## REQ-006: Modern 2026 UI Design
Premium, state-of-the-art visual design using 2026 trends: glassmorphism, mesh gradients, fluid animations, micro-interactions, dark mode. Indian tricolor-inspired accent palette.

## REQ-007: Responsive & Accessible
Fully responsive across desktop, tablet, and mobile. Meets WCAG 2.1 AA accessibility standards.

## REQ-008: Lightweight (< 10MB)
Total GitHub repository size must remain under 10MB. No heavy frameworks or large assets. Politician data as compressed JSON.

## REQ-009: Search & Filter
Global search across MPs, MLAs, constituencies, parties, FAQ content. Real-time filtering with debounce. State and party filter dropdowns.

## REQ-010: Interactive Quiz
Quiz section testing users' knowledge of Indian democracy, elections, and the constitution.
